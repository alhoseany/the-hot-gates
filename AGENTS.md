# Project instructions

The user requires this game to run locally only. The user explicitly authorized versioning and pushing source to GitHub on a new branch. Do not publish or deploy the game to a hosting service unless the user explicitly changes the local-only requirement. Keep development and preview servers bound to 127.0.0.1.

The retained `.openai/hosting.json` identifies a previously published private Site solely so its removal can be completed. Its presence does not authorize publishing. The available Sites tools did not expose unpublish or deletion when the user requested removal.
